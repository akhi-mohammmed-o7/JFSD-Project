4. DATA MODEL SPECIFICATION (model/Product.java)
----------------------------------------------------------------------
Target Package: com.example.catalog.model

Annotations required:
- @Entity
- @Table(name = "product")

Fields ONLY:
- id (Long, @Id, @GeneratedValue(strategy = GenerationType.IDENTITY))
- name (String)
- description (String)
- price (Double)

Implementation requirements:
- Standard default constructor (no-args)
- Constructor with all fields
- Standard Getters and Setters for all fields
- NO Lombok annotations (@Data, @Getter, @Setter, etc.)

5. REPOSITORY SPECIFICATION (repository/ProductRepository.java)
----------------------------------------------------------------------
Target Package: com.example.catalog.repository

Type: Interface
Annotation: @Repository
Extends: JpaRepository<Product, Long>

Requirements:
- Keep the interface body completely empty.
- Do NOT add custom query methods.

----------------------------------------------------------------------
6. REST CONTROLLER SPECIFICATION (controller/ProductController.java)
----------------------------------------------------------------------
Target Package: com.example.catalog.controller

Annotations:
- @RestController
- @RequestMapping("/api/products")

Dependency Injection:
- Inject ProductRepository via Constructor or @Autowired.

Endpoints to implement:
1. GET /api/products
   - Method: getAllProducts()
   - Response: List<Product>, HTTP 200 OK
2. GET /api/products/{id}
   - Method: getProductById(@PathVariable Long id)
   - Response: Product (or 404 Not Found if missing), HTTP 200 OK
3. POST /api/products
   - Method: createProduct(@RequestBody Product product)
   - Response: Saved Product, HTTP 201 Created
4. PUT /api/products/{id}
   - Method: updateProduct(@PathVariable Long id, @RequestBody Product updatedProduct)
   - Behavior: Fetch product by ID, update name/description/price, save back to repository
   - Response: Updated Product (or 404 Not Found), HTTP 200 OK
5. DELETE /api/products/{id}
   - Method: deleteProduct(@PathVariable Long id)
   - Response: HTTP 200 OK or 204 No Content
