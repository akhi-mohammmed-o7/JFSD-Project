Layer ResponsibilitiesBootstrap Class (CatalogApplication.java)Annotated with @SpringBootApplication.Houses the main() method to start the embedded Tomcat web server on port 8080.Triggers Spring Boot component scanning across com.example.catalog.Domain Entity (model/Product.java)Represents the core product data model.Annotated with @Entity and @Table(name = "product").Encapsulates product properties with standard Java getters, setters, and constructors.Data Access Repository (repository/ProductRepository.java)Extends JpaRepository<Product, Long>.Inherits pre-built persistence methods (save, findAll, findById, deleteById) without requiring manual SQL implementations.REST Controller (controller/ProductController.java)Annotated with @RestController and @RequestMapping("/api/products").Receives incoming HTTP requests, maps JSON payloads to Java objects via @RequestBody, delegates database interactions to ProductRepository, and formats outgoing JSON responses.4. 7. Operational & Execution LifecycleInitialization:Executing mvn spring-boot:run compiles the application, downloads Maven dependencies, generates the H2 database schema from Product.java, populates initial records if data.sql exists, and binds embedded Tomcat to port 8080.Request Execution Flow (Example: POST /api/products):Postman sends HTTP POST to http://localhost:8080/api/products with header Content-Type: application/json.Jackson deserializes the JSON body into a Java Product object.ProductController.createProduct(@RequestBody Product product) calls productRepository.save(product).Hibernate executes an INSERT INTO product ... statement on the H2 database.H2 assigns a generated id and confirms record creation.The saved entity is serialized to JSON and returned with HTTP status 201 Created.
